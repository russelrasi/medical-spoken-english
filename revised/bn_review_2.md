## Class 3: Daily Routine & the Present Simple Tense

| English | Bangla (current) |

| Daily Routine & the Present Simple Tense | দৈনন্দিন রুটিন ও Present Simple Tense |

| Talk about a typical college day for one and a half minutes. | কলেজের একটি সাধারণ দিন নিয়ে দেড় মিনিট কথা বলবে। |

| Rule 1: The Present Simple is for things that happen regularly, not right now. | নিয়ম ১: Present Simple নিয়মিত ঘটা কাজের জন্য, এই মুহূর্তের কাজের জন্য নয়। |

| For he, she and it, add -s to the verb. For everyone else, no -s. | he, she, it-এর ক্ষেত্রে ক্রিয়ায় -s যোগ হয়। বাকি সবার ক্ষেত্রে -s হয় না। |

| Answer 'What are you doing?' naturally on a phone call. | ফোনকলে 'What are you doing?' প্রশ্নের স্বাভাবিক উত্তর দেবে। |

| Rule 1: The Present Continuous is am / is / are plus verb-ing, for actions happening now. | নিয়ম ১: Present Continuous হলো am / is / are + verb-ing, যা এখন ঘটছে এমন কাজের জন্য। |
| Both parts are compulsory. 'I studying' is wrong, and so is 'I am study'. | দুইটি অংশই বাধ্যতামূলক। 'I studying' ভুল, 'I am study'-ও ভুল। |
| Spelling: a single final consonant doubles: sit → sitting, run → running. A final -e drops: write → writing, take → taking. | বানান: শেষে একটি ব্যঞ্জনবর্ণ থাকলে দ্বিগুণ হয়: sit → sitting, run → running. শেষে -e থাকলে বাদ যায়: write → writing, take → taking. |
